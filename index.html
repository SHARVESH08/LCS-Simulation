What is LCS?

The Longest Common Subsequence (LCS) problem asks: given two sequences X and Y, find the longest sequence that appears in both — but the characters don't have to be contiguous.

A subsequence is formed by deleting some elements from the original without changing the relative order. For example, ACE is a subsequence of ABCDE.

X = A B C B D A B
Y = B D C A B A
LCS = B C B A  (length 4)

This is different from the Longest Common Substring problem, where characters must be contiguous. LCS is more flexible and is a core problem in computer science.

💡 LCS is not always unique — multiple sequences of the same maximum length can exist. The algorithm finds one of them.

🧠
The Algorithm — Dynamic Programming

LCS is solved optimally using bottom-up dynamic programming. We build a 2D table dp[i][j] where each cell stores the LCS length of the prefixes X[1..i] and Y[1..j].

  • Initialize a (m+1) × (n+1) table filled with 0. The extra row/column represents the empty prefix (ε).
  • For each pair (i, j), check if X[i] == Y[j].
  • If they match: dp[i][j] = dp[i-1][j-1] + 1 — extend the diagonal subsequence.
  • If they don't match: dp[i][j] = max(dp[i-1][j], dp[i][j-1]) — take the best from above or left.
  • Record an arrow at each cell (↖, ↑, ←) for backtracking.
  • After filling the table, backtrack from dp[m][n] following arrows to reconstruct the LCS string.

Recurrence Relation

// Base cases
dp[i][0] = 0,  dp[0][j] = 0

// If characters match
if X[i] == Y[j]:
  dp[i][j] = dp[i-1][j-1] + 1

// If characters don't match
else:
  dp[i][j] = max(dp[i-1][j], dp[i][j-1])

💻
Code Implementations

Here are clean implementations in Python and JavaScript.

Python
def lcs(X, Y):
    m, n = len(X), len(Y)

    # Build DP table
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if X[i-1] == Y[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])

    # Backtrack to find the LCS string
    result, i, j = [], m, n
    while i > 0 and j > 0:
        if X[i-1] == Y[j-1]:
            result.append(X[i-1])
            i -= 1; j -= 1
        elif dp[i-1][j] >= dp[i][j-1]:
            i -= 1
        else:
            j -= 1

    return dp[m][n], ''.join(reversed(result))

# Example
length, seq = lcs("ABCBDAB", "BDCABA")
print(length, seq)  # 4  BCBA
JavaScript
function lcs(X, Y) {
  const m = X.length, n = Y.length;
  const dp = Array.from({length: m+1},
               () => new Array(n+1).fill(0));

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (X[i-1] === Y[j-1]) {
        dp[i][j] = dp[i-1][j-1] + 1;
      } else {
        dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]);
      }
    }
  }

  // Backtrack
  let i = m, j = n, lcsStr = '';
  while (i > 0 && j > 0) {
    if (X[i-1] === Y[j-1]) { lcsStr = X[i-1] + lcsStr; i--; j--; }
    else if (dp[i-1][j] >= dp[i][j-1]) i--;
    else j--;
  }
  return { length: dp[m][n], sequence: lcsStr };
}

lcs('ABCBDAB', 'BDCABA');
// → { length: 4, sequence: 'BCBA' }
C++
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

pair<int, string> lcs(const string& X, const string& Y) {
    int m = X.size(), n = Y.size();

    // Build DP table
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (X[i - 1] == Y[j - 1])
                dp[i][j] = dp[i - 1][j - 1] + 1;
            else
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
        }
    }

    // Backtrack to reconstruct the LCS string
    string result;
    int i = m, j = n;
    while (i > 0 && j > 0) {
        if (X[i - 1] == Y[j - 1]) {
            result += X[i - 1];
            i--; j--;
        } else if (dp[i - 1][j] >= dp[i][j - 1]) {
            i--;
        } else {
            j--;
        }
    }
    reverse(result.begin(), result.end());
    return {dp[m][n], result};
}

int main() {
    string X = "ABCBDAB", Y = "BDCABA";
    auto [len, seq] = lcs(X, Y);
    cout << len << " " << seq << endl; // 4 BCBA
}

Time & Space Complexity

OperationComplexityExplanation
DP Table FillO(m × n)Every cell computed once
Space (standard)O(m × n)Full table stored for backtracking
Space (optimized)O(min(m, n))Single rolling row — use shorter string as columns
BacktrackingO(m + n)At most m+n steps along the path
Hirschberg's AlgorithmO(m × n) time, O(m+n) spaceFull LCS string in linear space
💡 If you only need the LCS length (not the actual string), you can reduce space to O(min(m,n)) using a single rolling row — orient the table so the shorter string defines the columns (swap X and Y if needed), then update that one row in place, carrying only the previous diagonal value in a temporary variable.

Real-World Applications

LCS is a foundational algorithm that powers many real tools you use daily:

🧬
Bioinformatics
DNA/protein sequence alignment; finding evolutionary relationships between genomes.
🔀
Git / Diff
The diff tool and Git use LCS to show what changed between file versions.
🤖
NLP & Plagiarism
Measuring similarity between texts, spell checking, and detecting copied content.
🗂️
Version Control
Merging file changes without conflicts by finding common structure between revisions.
🔍
Edit Distance
LCS is deeply related to Levenshtein distance; fewer LCS matches = more edits needed.
📝
Spell Check
Fuzzy string matching in IDEs and search engines uses LCS-based similarity scores.

🔗
Related Problems & Variants

  • Longest Common Substring Characters must be contiguous. Uses DP but resets on mismatch. O(m×n) time.
  • Shortest Common Supersequence Shortest sequence containing both X and Y. Length = m + n − LCS(X,Y).
  • Longest Increasing Subsequence LCS of X and sorted(X). Can be solved in O(n log n) with patience sorting.
  • Edit Distance (Levenshtein) Min edits (insert, delete, substitute) to transform X → Y. With insert/delete only, dist = m + n − 2×LCS. Standard Levenshtein (with substitution) is a separate DP and that formula does not apply.
  • Diff / Patience Diff Git's diff algorithm finds the LCS of unique lines between two files.
  • Hirschberg's Algorithm Computes full LCS string using only O(m+n) space via divide-and-conquer on the DP table.

⚗️
Key Insight — Optimal Substructure

LCS exhibits optimal substructure: the solution to the full problem contains optimal solutions to subproblems. This is why dynamic programming works perfectly here.

If X[m] == Y[n], this character must be in the LCS — we take it and recurse on the remaining prefixes. If they differ, at least one must be excluded, and we try both options and take the maximum.

Naive recursion solves this in O(2ⁿ) due to overlapping subproblems. DP memoizes each (i,j) pair, reducing it to O(m×n) — a dramatic improvement.

🚀 The subproblem overlap is the key: without memoization, the same lcs(i,j) call is made exponentially many times. DP solves each subproblem exactly once.
